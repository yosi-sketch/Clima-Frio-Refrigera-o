# Friomax Refrigeração Comercial & Industrial

Site institucional e página de vendas de alta performance para a **Friomax Refrigeração** (Friomax Indústria e Comércio de Refrigeração Ltda), fabricante especialista com mais de 30 anos no mercado (desde 1991), fabricando equipamentos com qualidade e eficiência na refrigeração comercial e industrial em Minas Gerais e para todo o Brasil.

- **Paleta de Cores:** Extraída diretamente do logotipo oficial com o mascote de refrigeração e as 5 estrelas douradas:
  - Royal / Cobalt Blue Friomax (`#012B8E` / `#0047FF` / `#0A3AA9`)
  - Imperial Gold / Amber Star (`#F59E0B` / `#FACC15` / `#D97706`)
  - Deep Midnight Navy (`#07152B` / `#0B1E3F`)
  - Ice Cyan & Gotículas (`#38BDF8` / `#0284C7`)
  - Superfícies Assépticas Ice White (`#FFFFFF` / `#EFF6FF`)
  - WhatsApp de Ação Imediata (`#16A34A` / `#22C55E`)
- **Tipografia:** Montserrat (Headings) e Plus Jakarta Sans (Body)
- **Framework:** Next.js 16 (App Router), Tailwind CSS v4, Framer Motion, Lucide Icons
